# Security Policy

## Supported Versions

The following major versions of GoValidator are supported with security updates.
Use the latest release within your supported major version.

| Version | Security updates |
| ------- | ---------------- |
| 2.x     | Supported        |
| 1.x     | Supported        |

## Reporting Security Issues

Please report suspected vulnerabilities privately through GitHub's
[Report a vulnerability](https://github.com/rezakhademix/govalidator/security/advisories/new)
form. Do not disclose vulnerability details in public issues, discussions, or pull
requests before a fix is available and disclosure has been coordinated with the
maintainers.

Include the following information to help us investigate:

- The affected GoValidator version and your Go version.
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue, preferably with a minimal code example or
  proof of concept.
- Any known workarounds or suggested fixes.

Remove credentials, personal data, and other sensitive information from examples.
Use the private report to share follow-up details and coordinate disclosure.

We appreciate responsible disclosure and will make every effort to acknowledge
your contributions.
